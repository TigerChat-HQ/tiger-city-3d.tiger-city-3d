# TIGER CITY 3D

A realistic 3D city-building game targeting Android.

## Vision
- Realistic, mobile-friendly 3D city visuals.
- Build roads, homes, commercial buildings, and civic services.
- Vehicles, pedestrians, day/night lighting, and a growing city economy.
- Offline-first gameplay; online features will be added only when backend synchronization is implemented and tested.

## Development status
This repository is the project source repository. It is not an APK and does not yet contain a verified Android build.

## Planned first milestone
1. Create a minimal Unity project and a playable city-block prototype.
2. Add touch camera controls and placeable road/building tiles.
3. Add local save/load.
4. Profile and test on a real Android device before increasing visual quality.

## Build notes
The Unity Editor version and Android build configuration must be pinned before configuring a cloud build pipeline.
